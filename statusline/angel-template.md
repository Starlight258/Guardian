# Angel Template

```
      ˚₊‧꒰ა {HALO} ໒꒱ ‧₊˚
           /)  /)
        ૮({FACE})ა
         ꒰ঌ {ITEM} ໒꒱
            {FEET}
         ☁︎ {DECO} ☁︎
```

> 6줄 구조. `ʚɞ ⋆｡˚` 상단 장식 줄 없음.

| 변수 | 설명 | 예시 |
|------|------|------|
| `{HALO}` | 머리 위 장식 | `𓂋` `✧` `☾` `♡` |
| `{FACE}` | 표정 | `˶• ֊ •˶` `˶ᵔᗜᵔ˶)ﾉﾞ` `( • ᴗ - )` |
| `{ITEM}` | 가슴 장식 | `♡` `♡⃝` `✧` `☾` |
| `{FEET}` | 다리/포즈 | `╲╱` `╹╹` `𓂃` |
| `{DECO}` | 구름 장식 | `⋆` `♡` `𓍯` `☾` |
